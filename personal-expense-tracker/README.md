# Personal Expense & Budget Tracker

## Project Description
A personal finance management web application that allows users to record daily income and expenses, organize spending into hierarchical categories, set monthly budget limits with automated breach alerts, and visualize financial spending reports.

## Team Members
1. Student 1 - Backend & Architecture (Transaction Management & Category Hierarchy)
2. Student 2 - Engine & Logic (Budget Threshold Monitoring & Alert Notifications)
3. Student 3 - Frontend & Reporting (Dashboard UI, Analytics Charts & Report Exporter)

## Technologies
- HTML5, CSS3, JavaScript
- Node.js / Express
- PostgreSQL / SQLite
- Chart.js
